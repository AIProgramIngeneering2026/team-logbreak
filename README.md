# LogBreak

LogBreak — сервис автоматического анализа технических логов. Он помогает разработчикам и инженерам поддержки быстро находить в загруженных логах известные ошибки, оценивать серьёзность инцидента и сохранять воспроизводимый результат анализа.

Пользователь отправляет набор логов и выбирает анализаторы. Сервис создаёт задание анализа, выполняет выбранные проверки и позволяет получить его состояние и итоговый отчёт через HTTP API.

## Для кого

- разработчики, которые диагностируют ошибки приложений;
- инженеры поддержки, которые разбирают обращения пользователей;
- небольшие команды без отдельной платформы наблюдаемости.

## Что входит в систему

- приём логов через HTTP API;
- создание и отслеживание заданий анализа;
- подключаемые анализаторы с единым контрактом;
- поиск известных сигнатур ошибок и расчёт уровня серьёзности;
- хранение истории заданий и результатов;
- отмена ещё не завершённого задания.

## Что не входит в систему

- сбор логов напрямую с серверов и пользовательских устройств;
- мониторинг инфраструктуры в реальном времени;
- графический интерфейс;
- автоматическое исправление найденных проблем;
- хранение секретов и персональных данных из логов.

Перед отправкой данных пользователь обязан удалить секреты и персональные данные. Сервис ограничивает размер входных данных и срок хранения результатов.
