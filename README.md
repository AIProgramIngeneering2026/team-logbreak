# IndieFashion Radar

IndieFashion Radar — агрегатор публичной информации о небольших модных брендах. Он собирает публикации из заранее разрешённых Telegram-каналов и открытых сайтов брендов, приводит товары и новости к единому формату и помогает находить интересные коллекции и изменения модных тенденций.

Пользователь задаёт источники и параметры сбора. Сервис создаёт задание, получает новые публичные публикации, извлекает сведения о бренде, категории, цене, материалах и ссылке на оригинал, а затем выдаёт подборку и сводку через HTTP API.

## Для кого

- покупатели, которые ищут вещи небольших локальных брендов;
- стилисты и авторы тематических каналов, которым нужны свежие подборки;
- небольшие бренды, которые хотят видеть общие тенденции рынка;
- исследователи моды и ассортимента.

## Что входит в систему

- сбор новых публикаций из явно настроенных публичных Telegram-каналов;
- сбор открытых карточек и новостей с сайтов, которые разрешают автоматический доступ;
- подключаемые адаптеры источников с единым контрактом;
- нормализация названий брендов, категорий, цен, материалов и ссылок;
- поиск и фильтрация по бренду, категории, цене, источнику и дате;
- формирование сводки по популярным категориям, цветам и материалам;
- хранение истории заданий сбора и их результатов.

## Что не входит в систему

- доступ к закрытым каналам, личным сообщениям и данным пользователей Telegram;
- обход авторизации, CAPTCHA, `robots.txt`, платных подписок и других ограничений сайтов;
- оформление заказов, платежи и доставка;
- публикация материалов от имени брендов;
- копирование фотографий и полных текстов: сервис хранит краткие извлечённые данные и ссылку на оригинал;
- гарантированная оценка качества или подлинности товара;
- графический интерфейс в первой версии.

Система работает только с публичными источниками из списка разрешённых, соблюдает лимиты запросов и сохраняет происхождение каждого результата. Источник можно отключить без изменения управляющей логики.
